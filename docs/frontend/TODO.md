# Suzuran Cloud 前端待办清单

> 本文档记录前端实现的完整进度，采用**单页应用（SPA）+ 角色路由守卫**架构。

## 🎯 项目结构

```
frontend/app/                 # 统一单页应用（三端共用一个端口）
├── src/
│   ├── views/                # 页面组件
│   │   ├── Home.vue          # 首页
│   │   ├── Login.vue         # 登录页
│   │   ├── Forbidden.vue     # 403 禁止访问
│   │   ├── NotFound.vue      # 404 不存在
│   │   ├── provider/         # 服务商端视图
│   │   ├── tenant/           # 租户管理端视图
│   │   └── user/             # 用户端视图
│   ├── layouts/              # 布局组件
│   │   ├── ProviderLayout.vue
│   │   ├── TenantLayout.vue
│   │   └── UserLayout.vue
│   ├── stores/               # Pinia 状态管理
│   │   └── auth.ts           # 认证 Store
│   ├── router/               # Vue Router 配置
│   │   └── index.ts          # 路由 + 守卫
│   └── main.ts               # 应用入口
└── package.json
```
