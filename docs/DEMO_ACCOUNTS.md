## 🚀 快速开始

### 1. 插入演示数据

```bash
# 确保 PostgreSQL 已启动并运行
cd /Users/xrl/Documents/Repos/suzuran
./scripts/seed_demo_data.sh
```

### 2. 启动后端服务

```bash
cd backend
go run cmd/api/main.go
```

### 3. 启动前端服务

```bash
cd frontend/app
npm run dev
```

### 4. 访问应用

打开浏览器访问: `http://localhost:5173`

使用上述任一演示账户登录喵～ 🍥
